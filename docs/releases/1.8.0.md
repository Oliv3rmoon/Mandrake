**Mandrake 1.8.0: Beetle PSX with every picture setting.** The shaders, AMD FSR and CAS, generated frames and supersampling now work for the games you run on Beetle PSX, and the fixes of SwanStationPS5 1.6.1 are in.

## What changed

- **The picture settings work on Beetle PSX.** Its picture now goes to the screen the way SwanStation's does: the CRT and NTSC shaders, AMD FSR 1, AMD CAS, *Generate frames* and supersampling all apply, and Settings no longer locks them for a Beetle PSX game.
- **Generated frames count the game's own frames.** A Beetle PSX picture that only repeats the last one is now told apart, so *Generate frames* and *Show FPS* start from the game's real rate, as with SwanStation.
- **Beetle PSX upscale filter.** Settings > Graphics > Beetle PSX: Off (the default), Sharp pixels, Scale2x or xBR, applied to a Native picture before the shader.
- **The ANALOG button on Beetle PSX.** The light bar's *Analog mode* and *Left stick as D-pad: Auto* now follow Beetle PSX's DualShock.
- **PAL games at 60 Hz on Beetle PSX.** SwanStation's *Force NTSC Timings* (Settings > Graphics) now applies to both emulators.
- **Japanese** for every Beetle PSX text.
- **SwanStationPS5 1.6.1's fixes.** The sandbox unlock waits for a resident Lapy service first and asks LegacyJB and the PS5SX2 Helper before etaHEN's command server. The Game Boy LCD shader, which SwanStationPS5 1.6.0 removed, stays.

SwanStation's GPU renderer is unchanged. Built and checked by the host tests (Beetle PSX's frames uploaded through the app's own GPU code on a computer and read back pixel for pixel, rewind played back frame for frame); not yet run on a console. If a Beetle PSX game slows down with a heavy shader or generated frames, turn those off for it in *This game*.

## Install

- `PPSA98510.zip`: **Check for updates** in Settings > About installs it, or close Mandrake, extract the ZIP and copy its `PPSA98510` folder over your current one (usually `/data/homebrew/PPSA98510`). As after every update, the first start asks whether to start from the factory settings: **○** keeps yours.
- `SwanStationPS5-DiscDaemon.elf`: the disc daemon, sent once to the console's ELF loader (port 9021), as before.
- `SHA256SUMS`: the checksums of both. `gh attestation verify PPSA98510.zip -R Oliv3rmoon/Mandrake` checks that this repository's workflow built it.
