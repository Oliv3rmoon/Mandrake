**Mandrake 1.7.0: Beetle PSX, a second emulator.** For the games SwanStation runs badly, Mandrake now carries [Beetle PSX](https://github.com/libretro/beetle-psx-libretro) (Mednafen's PlayStation). SwanStation stays the default: every game runs on it until you choose otherwise.

## What changed

- **Choose the emulator, for one game or all.** Settings > System > **Emulator**: SwanStation or Beetle PSX. In *All games* it sets every game without settings of its own; in *This game* (**L2** / **R2** in Settings) only that game. It applies the next time the game starts. The shelf tags the games set to Beetle PSX, and the game menu shows which emulator is running.
- **Beetle PSX's settings.** Settings > Graphics > **Beetle PSX**: resolution (Native, the default, or 2x), dithering (on) and its widescreen hack (off). Region, fast CD loading, the startup intro, multitap, controllers, rumble, light guns, cheats, RetroAchievements, rewind, run-ahead, fast forward, quick resume and auto-save work with both emulators.
- **Saves kept apart.** Each emulator keeps its own save states and memory cards (Beetle PSX's in `states/beetle/` and `saves/beetle/`), so a save state of one never loads into the other. Your SwanStation saves stay where they were.
- **What only SwanStation does.** Beetle PSX draws on the CPU, so shaders, AMD FSR and CAS, generated frames, supersampling and HD textures stay SwanStation's, with its own settings (renderer, up to 16x, PGXP, true colour). For a Beetle PSX game, Settings shows them locked and says why.
- **Its BIOS.** Beetle PSX reads the same `bios/` folder and uses `scph5501.bin` (North America), `scph5500.bin` (Japan) or `scph5502.bin` (Europe), by name or by content. Without one it starts the game on its built-in OpenBIOS, and a notice says so.
- **Scanlines** (Settings > Display > CRT scanlines) work on Beetle PSX's picture too.

Built and checked by the host tests (Beetle PSX boots a homebrew test disc on a computer); not yet run on a console. Beetle PSX asks more of the console than SwanStation: if a game slows down on it, use Native resolution or go back to SwanStation for that game.

## Install

- `PPSA98510.zip`: **Check for updates** in Settings > About installs it, or close Mandrake, extract the ZIP and copy its `PPSA98510` folder over your current one (usually `/data/homebrew/PPSA98510`). As after every update, the first start asks whether to start from the factory settings: **○** keeps yours.
- `SwanStationPS5-DiscDaemon.elf`: the disc daemon, sent once to the console's ELF loader (port 9021), as before.
- `SHA256SUMS`: the checksums of both. `gh attestation verify PPSA98510.zip -R Oliv3rmoon/Mandrake` checks that this repository's workflow built it.
