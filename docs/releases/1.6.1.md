**Mandrake 1.6.1: renamed from Nightshade Station.** Renamed to Mandrake; same app, same title ID, your settings stay.

## What changed

- **The name.** The PS5 home screen, the shelf, the About page, the update texts, the notifications and every message say Mandrake, in all five languages, and so does the phone page. The About page's QR code opens Oliv3rmoon/Mandrake.
- **Updates.** The app asks [Oliv3rmoon/Mandrake](https://github.com/Oliv3rmoon/Mandrake/releases) for a newer release and installs it after checking `PPSA98510.zip` against `SHA256SUMS`. The release's files are named as before.
- **What stays.** The title ID (PPSA98510) and `/data/SwanStationPS5`, so it installs over Nightshade Station and keeps your memory cards, saves, save states, covers and settings. As after every update, the first start asks whether to start from the factory settings: **○** keeps yours.

## Install

- `PPSA98510.zip`: close Nightshade Station, extract the ZIP and copy its `PPSA98510` folder over your current one (usually `/data/homebrew/PPSA98510`), or install it from Nightshade's Settings > Apps. Nightshade Station 1.6.0 does not offer this release itself, because it takes release files only from its own old address; from this release on, **Check for updates** applies the next one.
- `SwanStationPS5-DiscDaemon.elf`: the disc daemon, sent once to the console's ELF loader (port 9021), as before.
- `SHA256SUMS`: the checksums of both. `gh attestation verify PPSA98510.zip -R Oliv3rmoon/Mandrake` checks that this repository's workflow built it.
